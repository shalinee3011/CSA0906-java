# Task B4 – Metadata and Migration

Run MetadataInspector with MySQL Connector/J and DB_USER / DB_PASSWORD environment variables set. The program reports database product, server version, JDBC driver version and tables. Metadata is useful when moving the application to another server because it exposes product and driver differences.

MigrationPlan.md gives the required migration workflow. Complete and run a migration driver using the actual legacy-file schema and CSV parser selected for the project, then save its failure report and console output as evidence.
